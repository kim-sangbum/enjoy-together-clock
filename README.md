# ⏰ Enjoy Together - 시계 맞추기 게임

가족 가훈인 **"Enjoy Together"**를 바탕으로, 아이가 시계 보는 법과 시간의 흐름을 재미있게 배울 수 있도록 직접 제작한 모바일 친화적 교육용 웹 게임입니다.

🚀 **[게임 플레이하기 (Live Demo)](https://willowy-treacle-84e43b.netlify.app/)**

---

## 💡 기획 배경
시각은 어느 정도 볼 줄 알지만 분 단위와 '시간의 차이(흐름)'를 헷갈려 하는 아이를 위해 기획되었습니다. 
단순한 퀴즈를 넘어, 레벨이 올라갈수록 제한 시간이 줄어들고 복합적인 사고를 요구하도록 설계하여 성취감을 느낄 수 있게 만들었습니다.

## ✨ 주요 기능 및 레벨 시스템

게임은 총 5단계의 레벨로 구성되어 있으며, 5문제를 맞출 때마다 다음 레벨로 넘어갑니다.

* **Level 1 (정각 및 30분 단위)**: 시계 읽기의 기초 (60초)
* **Level 2 (5분 단위)**: 분침의 움직임 파악 (50초)
* **Level 3 (1분 단위)**: 정밀한 시계 읽기 (40초)
* **Level 4 (~분 전 표현)**: "9시 10분 전"과 같이 실생활에서 자주 쓰는 역방향 시간 표현 학습 (40초)
* **Level 5 (시간 차이 계산)**: 두 개의 시계를 나란히 보여주고, 몇 분/몇 시간이 지났는지 시간의 흐름(흐른 시간) 유추 (60초)

### 🎯 디테일 및 학습 장치
* **정교한 오답(Distractor) 로직**: 무작위 오답이 아닌, 시와 분을 교묘하게 섞은 보기(예: 정답이 8:30일 때 9:30, 8:15 등)를 제공하여 시침과 분침을 모두 정확히 보도록 유도합니다.
* **시간 제한 (Progress Bar)**: 화면 중앙에 줄어드는 프로그레스 바를 배치해 긴장감과 재미를 더했습니다.
* **귀여운 UI/UX**: 파스텔 톤 배경과 통통 튀는 동물 이모지(🐰, 🐻, 🐥, 🦄) 애니메이션을 적용해 아이들의 흥미를 유발합니다.

## 🛠 기술 스택
빌드 과정이나 복잡한 환경 설정 없이, 브라우저에서 즉시 렌더링되도록 단일 HTML 파일 내에 모든 기술을 통합했습니다.

* **Frontend**: React 18 (CDN)
* **Styling**: Tailwind CSS (CDN)
* **Compiler**: Babel Standalone
* **Deployment**: Netlify Drop (Drag & Drop 배포)

## 📱 모바일 앱처럼 사용하는 방법
이 게임은 모바일 웹(Web App) 환경에 최적화되어 있습니다.
1. 스마트폰 브라우저(Safari, Chrome 등)에서 [접속 URL](https://willowy-treacle-84e43b.netlify.app/)을 엽니다.
2. 브라우저 메뉴에서 **'홈 화면에 추가(Add to Home Screen)'**를 선택합니다.
3. 바탕화면에 생성된 아이콘을 누르면 주소창 없이 전체화면 단독 앱처럼 즐길 수 있습니다.
